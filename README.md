# MinCoach

MinCoach is a Next.js app for AI-assisted workout coaching.

For beta deployment, see [BETA_DEPLOY.md](./BETA_DEPLOY.md).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Create `.env.local` with:

```txt
OPENAI_API_KEY=your_openai_key
OPENAI_MODEL=gpt-5-mini
```

The OpenAI key is only used in server routes under `app/api/coach/*`.
