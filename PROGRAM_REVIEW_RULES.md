# Manual Program Review Rules

This document defines how MinCoach should review a user-built training program before it is approved.

The goal is not to create a perfect bodybuilding system. The goal is to catch obvious mistakes, protect beginners, and make the program feel balanced, simple, and coach-made.

## Evidence Base

MinCoach should treat these as practical guardrails:

- Train major muscle groups regularly across the week.
- Build gradually instead of starting with maximum volume.
- Use enough weekly work for the goal, but avoid junk volume.
- Keep sessions realistic for the user's available time.
- Prefer stable, clear exercises for beginners, older users, uncertain users, or users with limitations.
- Pain, sharp discomfort, and unsafe progression override optimization.

Useful source anchors:

- ACSM resistance training update, 2026: https://acsm.org/resistance-training-guidelines-update-2026/
- ACSM resistance training key takeaways infographic, 2026: https://acsm.org/wp-content/uploads/2026/03/Resistance-Training-Position-Stand-infographic.pdf
- NSCA resistance training frequency article: https://www.nsca.com/education/articles/kinetic-select/determination-of-resistance-training-frequency/

## Review Levels

MinCoach should classify findings in three levels.

Red means the program has a clear problem:

- A major muscle group is missing across the week.
- Upper body has many press exercises but little or no pulling.
- A pass is much too long or much too short compared with the rest.
- A beginner has too many technically demanding exercises.
- The plan conflicts with stated pain, limitations, location, or equipment.

Yellow means the program is usable but could be improved:

- A muscle group is present but underdosed.
- A pass is slightly unbalanced.
- Exercise order could be cleaner.
- The week has some redundancy but not enough to block approval.

Blue means a coach suggestion:

- Add a complementary exercise.
- Swap to a more stable variant.
- Remove a redundant isolation exercise.
- Rename a pass to match what it actually trains.

## Weekly Balance

The review should count both muscle groups and movement patterns.

Muscle groups:

- Chest
- Back
- Shoulders
- Arms
- Quads
- Hamstrings/glutes
- Calves
- Core

Movement patterns:

- Horizontal press
- Vertical press
- Horizontal pull
- Vertical pull
- Squat/knee-dominant
- Hinge/hip-dominant
- Hamstring isolation
- Arm flexion
- Arm extension
- Core stability/flexion
- Calves

The coach should not only count exercise names. It should understand what each exercise does.

## Pass Size

Default targets by session length:

- 30 min: 3-4 exercises.
- 45 min: 4-5 exercises.
- 60 min: 4-6 exercises.
- 75+ min: 5-7 exercises for users who can recover from it.

Manual review rule:

- 0 exercises: cannot approve.
- 1-2 exercises: pass is too thin unless it is intentionally a small accessory day.
- 3 exercises: acceptable minimum.
- 4-6 exercises: normal range for most users.
- 7+ exercises: usually too much, especially for beginners or 60 min sessions.

## Upper Body Rules

Press and pull should be reasonably balanced.

Red flags:

- Chest/press exercises dominate the pass and back is missing.
- Three or more chest exercises in one pass while back has one or zero.
- Multiple exercises with nearly the same role, for example bench press, incline press, chest press, and flyes in the same short program.

Good suggestions:

- Remove the lowest-value duplicate chest exercise first.
- Add one horizontal pull, such as seated row or dumbbell row.
- Add one vertical pull, such as lat pulldown, if the week lacks it.
- Add arms only after the main push/pull balance is acceptable.

Example:

If Pass 1 has bench press, dumbbell press, incline dumbbell press, flyes, chest press, and lat pulldown:

- Keep 1-2 main chest presses.
- Remove flyes or chest press first.
- Add a row.
- Consider one arm exercise if there is room.

## Lower Body Rules

A lower body pass should not be only quad and calves unless the user has a specific reason.

Red flags:

- Benpress + leg extension + calves, with no hamstrings or glutes.
- No lower body work across the week.
- A lower body pass with only 2-3 exercises while upper body has 6+ exercises.

Good suggestions:

- Add hamstring curl if the user is at a gym.
- Add RDL only when the user has enough experience and no relevant back limitation.
- Add hip thrust/glute bridge when glutes/hip extension are missing.
- Keep calves as accessory, not the main lower body solution.

## Experience Rules

Beginner:

- Prefer stable machines, cables, and clear dumbbell exercises.
- Avoid too many advanced free-weight exercises at once.
- Keep volume moderate and easy to repeat.
- Default to RIR 2-3.

Intermediate:

- More combinations are allowed.
- Baseline volume can be higher.
- RIR 1-3 is usually fine depending on exercise.

Experienced:

- More specialized splits and higher volume can be acceptable.
- Still flag obvious imbalance, unsafe pain conflicts, or junk volume.

## Recommendation Behavior

The coach should make concrete suggestions, not vague comments.

Bad:

- "Add more back."
- "Balance the program."
- "Consider legs."

Good:

- "Pass A has a lot of chest pressing. I would remove Flyes and add Seated Row."
- "Pass B is missing hamstrings. I would add Leg Curl."
- "Upper body has 5 press movements and 1 pull. I would add one row before approving."

Suggestions should appear inside the affected pass:

- Add suggestions: dimmed blue rows with a plus button.
- Remove suggestions: red-tinted rows on the existing exercise.
- The user can accept or dismiss each suggestion.

## Tone

The coach should be clear, not dramatic.

Use:

- "Jag hade ändrat detta innan vi startar."
- "Det här är lite för mycket bröst jämfört med rygg."
- "Pass B är tunt jämfört med Pass A."
- "Jag föreslår Lårcurl här eftersom baksida lår saknas."

Avoid:

- "Fel schema."
- "Dåligt upplägg."
- Long scientific explanations.
- Overconfident claims when the rule is only a soft preference.

## Approval Logic

The app should allow approval when:

- Every planned pass has at least one exercise.
- No red finding remains unresolved, or the user explicitly chooses to approve anyway.

The app should encourage review when:

- Any pass has fewer than 3 exercises.
- Any pass has more than 6 exercises.
- A major muscle group is missing.
- Press/pull or upper/lower balance is clearly off.
- The program conflicts with limitations.

The app should not block minor yellow findings.
